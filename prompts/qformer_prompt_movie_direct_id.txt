# Variant of qformer_prompt_movie.txt with the SeLLa-style DIRECT ID tokens.
#
# <UserID> injects ONE soft token user_id_proj(e_u) and <ItemID> injects ONE
# soft token item_id_proj(e_i) (placed right next to the target's Q-Former
# tokens), so the LLM sees BOTH raw MF vectors unreduced. In principle it can
# then reconstruct the MF dot product e_u . e_i — i.e. this path lower-bounds
# the model at the MF baseline, with the Q-Former semantic channel on top.
# SeLLa injects exactly these two tokens (plus <Warm_ID>).
#
# Requires model.direct_id_tokens: true — with the flag off, <UserID>/<ItemID>
# are stripped from the prompt and this file degenerates to the full prompt.
# <Warm_ID> is stripped automatically while model.qformer_config.warm_token is
# False.
