# Variant of qformer_prompt_movie.txt with <ItemTitleList> REMOVED.
#
# Purpose: the full prompt gives the model the user's history twice — once as 8
# pooled soft tokens (<UserProfile>) and once as plain text titles
# (<ItemTitleList>). Those are redundant, and the text path is the one Qwen2
# already understands from pretraining, so LoRA has no reason to learn to read
# the soft tokens. Removing the text makes <UserProfile> the ONLY route by
# which history reaches the LLM.
#
# Read the result as: uAUC up  -> redundancy was the problem, soft tokens do
# carry history; uAUC down hard -> soft tokens cannot substitute for the titles,
# so the bottleneck is Stage 1/2 representation quality, not the prompt.
#
# Note <TargetItemTitle> is deliberately KEPT: this isolates ONE variable (the
# history channel). <Warm_ID> is stripped automatically while
# model.qformer_config.warm_token is False.
